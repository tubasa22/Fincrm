## 사용 방법

1. 위 링크 접속
2. Google 계정으로 로그인
3. 간단한 초기 설정 후 바로 사용

별도 설치 불필요 · 모바일/PC 모두 지원

한 번 온라인 상태로 로그인해 동기화하면, 이후 오프라인 상태에서도 로그인 화면의 **📴 오프라인 모드** 버튼으로 마지막 동기화 데이터를 조회할 수 있습니다. 오프라인에서는 조회만 가능하며 저장·수정은 온라인 상태에서 진행하세요.

---

## 현재 상태 / 최근 업데이트

- 오프라인 모드: 마지막 동기화 데이터를 로컬 캐시로 조회 가능
- 파일 구조 정리: 화면 스타일과 기능 코드를 `css/`, `js/` 폴더로 분리 완료
- 고객 등록: 이름·성·도시 입력 시 단어 첫 글자를 자동으로 대문자 처리
- 피드백: 사용자 프로필 정보와 로컬 전송 기록을 함께 보존
- 안정성: 사용되지 않는 내부 개발 도구 호출을 정리
