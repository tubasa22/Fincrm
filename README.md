## 사용 방법

1. 위 링크 접속
2. Google 계정으로 로그인
3. 간단한 초기 설정 후 바로 사용

별도 설치 불필요 · 모바일/PC 모두 지원

한 번 온라인 상태로 로그인해 동기화하면, 이후 오프라인 상태에서도 로그인 화면의 **📴 오프라인 모드** 버튼으로 마지막 동기화 데이터를 조회할 수 있습니다. 오프라인에서는 조회만 가능하며 저장·수정은 온라인 상태에서 진행하세요.

## 현재 상태 / 최근 업데이트

- 표기 통일: 이름과 도시는 자동 대문자로 입력되며, 화면에 표시되는 날짜는 MM/DD/YYYY 형식으로 보여줍니다.
- 로그인: 사용하지 않는 신청·액세스 코드 화면을 제거하고 Google 로그인과 데모 모드 중심으로 간소화했습니다.
- 고객 목록: 액션을 활성 토글·파일·삭제로 간소화하고, 상세·수정·전화·문자는 고객 상세 화면에서 제공합니다.
- 고객 상태: 목록에서 활성·비활성을 즉시 전환하고, 비활성 고객은 흐린 행과 배지로 구분합니다.
- 상품 정보: 가입 회사와 구체적 상품명을 따로 입력하고, 상품명 자동완성과 고객 목록의 보조 표시를 지원합니다.
- 가입 상품: 자유롭게 입력하고, 기존 고객의 상품명을 자동완성 추천으로 활용합니다.
- Medigap 등록: 약보험(PDP) 상품을 함께 입력하고, 기존 고객 수정 시 두 상품을 자동으로 나누어 표시합니다.
- 고객 등록: 어떤 플랜을 선택해도 약 목록 등 상담·가입 상세 정보를 입력할 수 있습니다.
- 대시보드: 플랜별 현황을 간결한 막대 그래프로 표시하고, 항목을 누르면 해당 고객 목록으로 이동합니다.
- 상담 이력: 메모를 탭 순서와 무관하게 전용 시트에서 안정적으로 조회·저장합니다.
- 가입 상품: 새 등록·수정 화면의 보험사 선택을 실제 취급 보험사로 간소화했습니다.
- 브랜드: MedCare CRM과 의료 아이콘 ⚕️으로 화면 표시를 새롭게 정리했습니다.
- 최근 정리: 오프라인 모드, 고객 등록 입력 및 내부 안정성을 개선했습니다.
- 고객 등록: 빠른 연속 저장으로 인한 중복 저장을 방지했습니다.
- 고객 목록: 수정 후에도 적용 중인 검색·플랜 필터가 유지됩니다.
- 로그인: 로그아웃 후 온라인으로 다시 로그인할 때 오프라인 상태가 남지 않도록 개선했습니다.
- 메시지: Twilio 기반 발송 기능 대신 기기의 기본 문자 앱으로 바로 연결합니다.
- 외부 앱 안내: 문자·전화 앱을 열 수 없을 때 Phone Link 연결 상태를 안내합니다.
- 화면 정리: 사용하지 않는 자동화 탭과 고객 상세의 카카오 단축 버튼을 제거했습니다.
- 오프라인 모드: 마지막 동기화 데이터를 로컬 캐시로 조회 가능
- 파일 구조 정리: 화면 스타일과 기능 코드를 `css/`, `js/` 폴더로 분리 완료
- 고객 등록: 이름·성·도시 입력 시 단어 첫 글자를 자동으로 대문자 처리
- 안정성: 사용되지 않는 내부 개발 도구 호출을 정리
