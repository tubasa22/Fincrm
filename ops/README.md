서로의 작업 공간이 보이지 않습니다. 결정과 지시는 전부 `ops/`를 거칩니다.

## 구조

- `ops/README.md` — 규칙
- `ops/STATE.md` — 지금 상태 한 장 (항상 덮어씀)
- `ops/decisions/` — 결정 기록, 번호순, 지우지 않음
- `ops/specs/` — 설계 → 구현 지시서, 번호순

## 규칙

1. **결정은 지우지 않는다.** 바뀌면 새 번호로 쓰고 옛 파일에 `상태: 대체됨 → 0007`만 적는다
2. **설계와 구현을 나눈다.** Claude가 `specs/`에 지시서 → Codex가 구현 → `## 결과` 채움 → `상태: 완료`
3. **STATE.md는 항상 현재.** 누가 무엇을 들고 있는지, 다음 차례가 누구인지
4. **커밋 메시지에 누가 했는지** — `[claude]` `[codex]` `[jaden]`
5. **AEP(~2026-12-07) 중에는 추가와 읽기만.** 모든 spec에 `AEP-safe: yes|no`

이력 관리는 git이 합니다. `ops/`에는 현재 상태와 이유만 적고 변경 내역은 적지 않습니다.
